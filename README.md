# Validador de Ubicación

Aplicación web para validar la ubicación de materiales en bodega mediante el escaneo de códigos de barras.

## Objetivo

Reducir errores de almacenamiento comparando el código de la impresión del material con el código de la casilla donde se encuentra ubicado.

La aplicación fue diseñada para apoyar las tareas de recepción, almacenamiento y control operacional, permitiendo realizar validaciones rápidas directamente desde un teléfono móvil o un computador.

---

## Funcionalidades

- Lectura de códigos de barras mediante la cámara del dispositivo.
- Inicio del proceso escaneando cualquiera de los dos códigos.
- Comparación automática entre ambos códigos.
- Normalización automática de ubicaciones.
- Compatible con teléfonos móviles, tablets y computadores.
- No requiere instalación.

---

## Uso

1. Abrir la aplicación.
2. Escanear el código de la impresión o el código de la casilla.
3. Escanear el segundo código.
4. Revisar el resultado de la comparación.
5. Presionar **Nueva revisión** para comenzar nuevamente.
